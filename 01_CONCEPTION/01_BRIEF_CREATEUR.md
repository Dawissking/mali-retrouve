## 1. Positionnement de marque

**RECOMMANDATION.** MALI RETROUVÉ est une plateforme numérique nationale malienne qui sert de pont entre les citoyens, les centres de dépôt et l'administration pour la gestion des documents et objets perdus ou trouvés.

Le positionnement doit concilter :

- **Sérieux institutionnel** — il s'agit d'un service public national
- **Proximité citoyenne** — l'usager est un particulier en détresse (perte de pièce)
- **Fiabilité** — la confiance est centrale pour que les citoyens déclarent et récupèrent
- **Accessibilité** — le public malien est très mobile-first et inclut des populations peu lettrées, analphabètes, et des zones à faible connectivité

## 2. Personnalité de marque

| Trait | Expression |
|---|---|
| **Fiable** | Sérieux dans les procédés, transparence dans les échanges |
| **Accessible** | Compréhensible par tous, même analphabètes |
| **Respectueux** | Ne juge pas, traite avec dignité |
| **Nationalement ancré** | Racine malienne, valeur culturelle |
| **Moderne** | Numérique, fluide, pas burocratique excessif |
| **Rassurant** | L'expérience doit apaiser, pas inquiéter |

## 3. Valeurs à transmettre

1. **Confiance** — le système protège les données et les biens
2. **Réduction du risque** — un document perdu = un risque d'usurpation maîtrisé
3. **Inclusivité** — accessible quel que soit le niveau d'instruction
4. **Souveraineté** — service public malien, pas étranger
5. **Efficacité** — gagner du temps vs. les démarches traditionnelles
6. **Traçabilité** — rien n'est perdu, tout est journalisé
7. **Respect de la vie privée** — protection des données (Loi 2013-015)

## 4. Publics cibles

| Public | Caractéristiques | Besoin principal |
|---|---|---|
| **Citoyens urbains (18-50 ans)** | Téléphone mobile, CNI, français/bambara | Déclarer perte et récupérer rapidement |
| **Citoyens ruraux (analphabètes)** | 2G, bambara, peu d'éducation | Processus simple, images évocatrices |
| **Agents de centre** | Tablette ou ordinateur, formation courte | Interface claire, validation simple |
| **Administration (Bamako/Regions)** | Dashboard web, français | Statistiques, contrôle, conformité |
| **Partenaires institutionnels** | Rapport, français, visuels offiels | Lien de confiance, image professionnelle |

## 5. Perception recherchée

- **Par le citoyen :** "Je me fais comprendre, on me rassure, c'est fiable"
- **Par l'administration :** "C'est un service public moderne, sérieux, intégré à notre parc"
- **Par le commanditaire :** "C'est un projet qui rend justice à notrePays, qui respecte les règles"

## 6. Ce que la marque doit éviter

| Risque | Description |
|---|---|
| Trop corporate | Rien de "call center" ou "banque privée" |
| Trop informel | Pas de style "startup tech" ou "jeune tumultueux" |
| Trop technique | Pas de jargon, pas de logos abstraits incompréhensibles |
| Trop culturel | Pas de folklorisme exagéré (manque de modernité) |
| Trop institutionnel | Pas de froid bureaucratique, perte d'humanité |
| Confusion identité | Doit se distinguer clairement de micati.site/CNI (service existant) |
| Ambigüité | Le logo/message doit être compréhensible au premier regard |

## 7. Critères d'un logo réussi

| Critère | Exigence |
|---|---|
| Mémorabilité | Reconnaissable en 5 secondes |
| Lisibilité | Lisible en 16px (favicon, bouton) |
| Simplicité | Dessinable d'un trait, sans détail fin |
| Neutralité culturelle | Pas de symbole religieux, pas de drapeau politique |
| Évocation métier | Doit évoquer "recherche", "connexion", "retour" |
| Robustesse | Fonctionne en couleur ET en monochrome |
| Gravabilité | Lisible imprimé sur papier, carte plastique, vêtement |
| Accessibilité | Ne crée pas de confusion pour daltoniens |

## 8. Contraintes du logo

| Domaine | Contraintes |
|---|---|
| Formats | Vectoriel (SVG, EPS), PNG, ICO |
| Versions | Couleur, monochrome, négatif |
| Tailles | 512px, 128px, 64px, 32px, 16px |
| Usages | Application mobile, site web, impression, vêtements |
| Marges de sécurité | Zone non entrecroisée autour du logo |
| Couleurs interdites | Ne pas forcer le logo sur fond de couleur primaire |
| Ratio | Square ou paysage (pas portrait) |
| Texte | Le mot "MALI RETROUVÉ" en complément, police définie dans le design system |

## 9. Critères de lisibilité mobile

| Élément | Exigence |
|---|---|
| Logo favicon | 16x16 px — forme carrée, symbole seul ou initiales |
| Logo app | 180x180 px — icône + nom |
| Logo notification | 64x64 px — symbole essentiel |
| Bouton | 44x44 px minimum — touche tactile |
| Ratio 2G | Assets < 50KB, palette limitée |

## 10. Critères institutionnels

| Exigence | Commentaire |
|---|---|
| Sérieux | Le logo doit pouvoir figurer sur un document officiel scellé |
| Neutralité | Aucun parti politique, aucune religion, aucune origine ethnique |
| Nationalité | Doit évoquer le Mali sans être un drapeau |
| Équité | Ne privilégie aucun groupe linguistique ou régional |
| Durabilité | Style qui ne vieillira pas en 5 ans |

## 11. Critères culturels

| Exigence | Commentaire |
|---|---|
| Localisation | Le colibri (Proposition B) est ancré culturellement — oiseau rapide, messager |
| Langue | Le bambara est la langue la plus parlée — le texte doit s'adapter |
| Symbolisme | Éviter les symboles islamiques ou chrétiens explicites |
| Accessibilité analphabète | Le logo doit être compris sans lecture |
| Régions | Le logo doit pouvoir être appliqué dans toutes les 20 régions |

## 12. Critères d'accessibilité

| Élément | Exigence |
|---|---|
| Contraste | Logo couleur vs fond : 4.5:1 minimum |
| Daltonisme | Vérifier avec simulateurs de daltonisme (deutéranopie, protanopie, tritanopie) |
| Vision faible | Logo lisible en grand format et en petit format |
| Couleur seule | Le sens ne doit pas dépendre uniquement de la couleur |
| ARIA | Logo avec attribut `alt` approprié (ex: "MALI RETROUVÉ — Plateforme nationale des objets perdus et retrouvés") |

## 13. Critères de mémorisation

| Facteur | Exigence |
|---|---|
| Shape | Forme géométrique ou organic simple |
| Repetition | Usage systématique dans tous les points de contact |
| Distinction | Doit se distinguer des logos existants (micati, gouvernement, ONG) |
| Storytelling | Le logo doit raconter une histoire simple (perte → recherche → retour) |

## DIRECTIONS VISUELLES

### Direction 1 — Institutionnel moderne

**Statut : PROPOSITION — À VALIDER**

| Aspect | Analyse |
|---|---|
| **Forces** | Sérieux institutionnel (⭐⭐⭐⭐), adaptable aux supports officiels, design system éprouvé, bonne lisibilité |
| **Faiblesses** | Peut sembler trop "corporatif", moins humain, moins chaleureux pour les analphabètes |
| **Contexte d'utilisation** | Interfaces administratives, documents officiels, rapport institutionnel |
| **Risques** | Perception de distance ou de bureaucratie par les citoyens |
| **Recommandations d'amélioration** | Associer le bleu institutionnel à une touche de chaleur (vert ou orange) pour adoucir le côté trop "bank-like". Ajouter des illustrations humaines pour compenser l'aspect froid. |

### Direction 2 — Éthique minimaliste

**Statut : PROPOSITION — À VALIDER**

| Aspect | Analyse |
|---|---|
| **Forces** | Inclusif, neutre, excellente lisibilité mobile, faible empreinte réseau, design épuré |
| **Faiblesses** | Peut manquer d'identité visuelle forte, perception de "rien" par les citoyens peu attentifs |
| **Contexte d'utilisation** | Interfaces citoyennes primaires, mobile-first, faible connexion |
| **Risques** | Trop austère, peur de l'abandon ou confusion avec d'autres services publics minimalistes |
| **Recommandations d'amélioration** | Ajouter une couleur d'accent vive pour les actions (vert ou orange). Introduire un micro-pattern ou texture subtile pour éviter l'uniformité. |

### Direction 3 — Communautaire

**Statut : PROPOSITION — À VALIDER**

| Aspect | Analyse |
|---|---|
| **Forces** | Forte adéquation culturelle, rassurant pour les citoyens peu lettrés, chaleureux, évoque la solidarité |
| **Faiblesses** | Risque de sembler "trop jeune" ou informel pour l'administration, plus lourd en assets graphiques |
| **Contexte d'utilisation** | Interfaces citoyennes, campagnes de sensibilisation, communication publique |
| **Risques** | Perception d'informel par les institutions, risque de rejet par les administrations |
| **Recommandations d'amélioration** | Adoucir le style "jeune" en évitant les illustrations trop colorées. Introduire des éléments géométriques plus sobres pour l'interface admin. |

## RECOMMANDATION — À VALIDER

### Direction recommandée : Direction 3 — Communautaire modernisée

**Justification :**

1. **Pertinence culturelle maximale** : La palette vert/terre cuite/beige évoque la terre du Mali, le lien avec le sol et le peuple. Très ancrée culturellement.

2. **Confiance utilisateur élevée** : Les tons chauds (vert, terre cuite) sont psychologiquement rassurants et associés à la nature, la croissance et la sécurité — idéal pour un service de restitution.

3. **Différenciation visuelle forte** : Contrairement au bleu institutionnel (très utilisé par les administration), le vert + terre cuite crée une identité distincte.

4. **Adaptabilité mobile** : Malgré une légère complexité supplémentaire, le design mobile-first de la direction 3 est compatible avec le MVP.

### Logo recommandé : Proposition A — Lien modernisé

**Justification :**

1. **Lisibilité 16px** : La forme géométrique des cercles entrelacés est plus lisible en micro-format que le colibri ou la clef.

2. **Universalité** : Le concept de "lien" / "connexion" est universellement compris, sans ambiguïté culturelle.

3. **Neutralité** : Aucun risque de confusion culturelle ou religieuse.

4. **Évocation métier** : Parfaitement évoque la mission : relier un perte à un trouvaille.

5. **Mémorabilité** : Le double-cercle entrelacé est mémorable et adaptable à de nombreuses tailles.

### Modifications nécessaires pour la combinaison Direction 3 + Logo A

1. **Palette hybridée** : Utiliser la palette 3 (vert, terre cuite, beige) avec le Logo A en vert `#2E8B57` au lieu de bleu.

2. **Correction de contraste** : Le vert `#2E8B57` sur fond blanc (3.5:1) est insuffisant pour le texte. Il faut :
   - Un vert plus foncé pour les titres/textes : `#1E5E3F` (4.5:1+ sur blanc)
   - Garder `#2E8B57` pour les éléments décoratifs et le logo

3. **Équilibre institutionnel** : Adoucir le vert vif pour éviter perception "too young". Introduire des éléments géométriques sobres (bordures droites) pour compenser la forme organique du colibri.

4. **Typographie** : Poppins/Nunito (direction 3) est plus chaleureuse que Montserrat/Open Sans (direction 1). Pour l'administration, monter une hiérarchie plus sobre pour les tableaux de bord.

5. **Illustration** : Introduire des illustrations légères de personnes (comme proposé dans direction 3) mais dans un style plus sobre — lignes simples, palette limitée — pour éviter le "trop coloré".

6. **États couleurs** : Ajouter explicitement :
   - Succès : `#2E8B57` (vert existant)
   - Erreur : `#E53935` (rouge ajouté)
   - Alerte : `#FF6B35` (orange existant de §17.1)

### Risques de la combinaison hybride

| Risque | Mitigation |
|---|---|
| Vert perçu comme "bon succès" | Utiliser le gris foncé `#333333` pour les textes, vert uniquement pour logo/actions |
| Trop chaleureux pour administration | Introduire des versions sobres (bordure grise) pour les interfaces admin |
| Difficulté de gravure | Simplifier le logo A en version linéaire (2 traits) pour la gravure |
| Incompatibilité avec micati | Le bleu `#003366` de micati n'apparaît pas — bonne différenciation |
